# SnapPop Supplier Showcase

A responsive, original product showcase page for a supplier of kids' digital cameras. The design is inspired by the merchandising rhythm of modern product pages, without copying Amazon branding, layout, or assets.

## Run locally

This is a dependency-free static site. From the repository root, serve it with any static server, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Included

- Responsive product hero with original CSS product illustration
- Product benefits, specifications, box contents, partner CTA, and FAQ
- Enquiry modal with client-side validation and success state
- Mobile navigation, smooth scrolling, focus states, and reduced-motion support
- No build step or external runtime dependencies
